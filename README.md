This repository contains the data preprocessing and data generation code for the SCDL3991 final report 'Robust Trajectory Modelling for Livestock Movement Estimation'.
This involves 3 scripts:
  - simulate_data.R: generation of data for simulation study for Aim 1
  - preprocess_cows.R: preprocessing pipeline for cattle GPS data (University of Queensland)
  - preprocess_sheep.R: preprocessing pipeline for sheep GPS data (Beef + Lamb New Zealand)

The raw GPS data and the farm boundary polygons (FGfarm_boundaries.geojson) are not included due to data sharing agreements.
